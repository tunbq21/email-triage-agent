# Email Triage Agent

- **Độ khó:** Beginner
- **Framework/Công nghệ:** LangChain
- **Kỹ năng đạt được:** Tool calling, Gmail API

## Mô tả Project
Tác nhân AI giúp phân loại, sắp xếp và quản lý hộp thư đến. Project này tích hợp trực tiếp với Gmail API, sử dụng tính năng tool calling để đọc, phân tích nội dung email và dán nhãn hoặc tự động phản hồi các email cơ bản.
